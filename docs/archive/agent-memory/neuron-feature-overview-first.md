Direction from the project owner on 2026-09-21, first stated for days: **every unit of work opens with an overview before the first block starts.** Since 2026-10-10 the unit is a feature ([[neuron-feature-plan]]). State how many blocks there are, what each covers in a line, and which are decisions versus implementation.

She asked for this after several days where the block count only emerged when she asked mid-session.

**Why:** she has roughly 7 focused hours a day and needs to judge the size at the start, while choosing scope or stopping is still cheap.

**How to apply:** open with a compact list, then start block one. Name the feature and block at the top of every block ("Feature 1, Finish writing — block 2 of 4"). Still one block at a time after that; see [[neuron-teaching-mode]].
