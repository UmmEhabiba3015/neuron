# Journal design system

`direction-lock.md` is the binding design document: colour, type, space, components, behaviour
and content, with the measured argument under each rule. This file describes how the system is
built as modules, and keeps the dated log of design decisions. Token values above are generated
from `system/tokens.json` by the build; edit them there.

## How the system is built

The product is moving, one module at a time, from one global stylesheet (`lock.css`) to modules:
one folder per component, layout primitive, section or page under `system/modules/`, each with
its markup (a render function), styles, optional script, `contract.json`, catalogue fixtures and
README. The plan is in the "Modular design system" plan doc; the rules are below.

- **Tokens.** `system/tokens.json` is the only source. The build writes them into `lock.css`
  (the generated TOKENS block), `dist/css/tokens.css` and the front matter of this file.
- **Layers.** `@layer tokens, base, legacy, layout, components, sections, pages`. The
  pre-module stylesheet sits in `legacy`, under every module, so an extracted module always wins
  over the rules it replaces. When `legacy` is empty, the migration is done.
- **Prefixes.** Project, layer and name: `aj-l-stack`, `aj-c-notice`, `aj-s-…`, `aj-p-…`.
  Every selector in a module starts from its own class; nothing names another module's class.
- **Parents own the space between children.** A module sets no outer margin or width. While
  the parents are still legacy CSS, their placement rules stay in `lock.css` and may set only
  placement (margin, width, grid and flex placement, `display:none`) and a module's exposed
  custom properties. `check-modules.mjs` enforces that.
- **Context travels through tokens and container queries,** never through selectors.
  Contexts that still come from legacy classes (`.device.d`, `.app.ios`) are marked
  `/* legacy-context: … */` in the module and listed by the checker as migration debt; they go
  when the shell becomes a layout module with a `data-platform` attribute.
- **Build output.** `node scripts/build.mjs` writes `dist/` (system.css, system.js,
  `assets/fonts.css`, one catalogue page per module, contracts, TypeScript props), `ASSETS.md`,
  this file's token values and `lock.css`'s generated blocks. On module branches only sources
  are committed; `dist/` and the generated exports are rebuilt in one commit per wave.
- **Inventory.** The component inventory stays closed at 37 (direction-lock.md §6). Layout
  primitives and sections are listed separately. A component folder not on the inventory fails
  the checks.
