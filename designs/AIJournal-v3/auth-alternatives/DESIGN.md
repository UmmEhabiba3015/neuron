# Retained account design

Plain paper is the selected design and is implemented in the main website and numbered sign-in/sign-up screens.

[Diagonal-light glass](inset-backgrounds/05-glass-diagonal-light.html) remains the only active standalone alternative. It opens directly with sign-in and sign-up, opaque forms, password confirmation and eye controls.

The merged plain-paper snapshot, its helpers and historical evidence are preserved outside this project. See [cleanup record](../docs/CLEANUP-2026-10-07.md). Main website checks use `node scripts/verify-website-preview.mjs`.
