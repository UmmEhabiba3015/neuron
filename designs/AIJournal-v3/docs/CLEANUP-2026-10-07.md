# Code cleanup, 7 October 2026

This is a maintenance revision. The approved design, routes, prototype scope,
microphone recovery, audio playback, motion timings and review override remain.

## Changes

- Removed the unused website conversion for text-based Show password buttons and
  its duplicated password CSS. Auth controls come from numbered source screens.
- Removed obsolete route repair aliases and label-based guessing. Authored links
  are validated during assembly. The active calendar-to-day fixture mapping stays.
- The website embeds common fonts, CSS and runtime once, alongside three markup
  profiles. It initializes a normal function instead of evaluating source text.
  Profile changes still snapshot drafts, entries, moods and scroll position;
  recording defers the profile change until the recorder is idle.
- Journal views cache their rows. Changes update the current view by entry key;
  hidden views synchronize when visited. Existing memo SVGs and playback controls
  are retained during edits and memory changes.
- `scripts/html-structure.mjs` shares element traversal, respecting comments,
  quoted attributes, void elements and raw-text elements.
- `scripts/portable-fonts.mjs` only reads and validates assets. File updates are
  explicit in `scripts/update-portable-fonts.mjs`.
- `scripts/build.mjs` orders source controls/recorder updates, state generation,
  header and companion normalization, font updates, exports, motion, guide and
  route audit. Lower-level builders remain available for a focused rebuild.
- Current Chromium/Firefox checks share disposable profiles, protocol transport,
  evaluation, screenshot capture and browser cleanup in `browser-harness.mjs`.
- Consolidated repeated overview/helper CSS and grouped auth breakpoint rules.
  Native, C3 and browser-capability rules remain because they still apply.
- Delivery packaging uses an explicit file list, timestamped output and refuses
  to overwrite existing packages. Verification artifacts are optional.
