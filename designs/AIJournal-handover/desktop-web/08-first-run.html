The emptiest screen in the product on the widest platform in it, which is the one combination where restraint stops being free. At 390 an empty screen looks like a small screen; at 1440 there is visibly room for a feature grid and there is not one. Every instinct a landing page has is to fill this, and the engagement rules forbid the whole vocabulary that would.
Not a landing page. The working application with nothing in it yet. No marketing copy, no feature grid, no badges, no sign-in wall, no scroll. The destination row is present and live, because the four places exist before you have written anything.
The opening statement fills its column, 972px, and sets on one line at 73 characters. It was frozen at 34ch once, which was a proxy mistaken for a rule.
Never an empty box: the composer carries a written prompt from a fixed human written set that rotates by day and needs no model. It is 700 and centred on the sheet's axis even though there is no sheet yet, which is fix 3 being a property of the shell rather than of Today: the place you write does not move when the day fills up.
